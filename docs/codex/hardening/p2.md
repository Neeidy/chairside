### 1. Consent — NOT CLOSED

**HIGH:** `Read Pending Answer` rejects the original C0/C1 characters covered by its `tampered` regex, but explicitly permits TAB, LF and CR. It then calls `trim()` before testing consent. Consequently, `"\nyes"` and `"yes\n"` become `"yes"` and pass when the model returns `confirm`, despite the node’s stated rule that a second line never consents. JavaScript `trim()` also removes boundary Unicode whitespace and U+FEFF.

The consent expression matches literal ASCII phrases with `/i`; it does not generally normalize Unicode look-alikes or remove interior zero-width and RTL characters. The one-line fold in `Merge State` applies to stored `recent_messages`, not the current text sent through this consent test. Evidence: `Read Pending Answer` and `Merge State` in the [staged Main workflow](/home/auditor/work/n8n/staged/workflow.main.sanitized.json).

### 2. Reschedule marker — NOT CLOSED

**MEDIUM:** The session-gap fix removes `reschedule_ask` on a new session, but within the same session the rewrite checks only the previous marker, current model intent `book`, and a bound target. An unrelated request for a new booking immediately after “what new day and time?” is therefore rewritten to `reschedule` and can move the existing booking after confirmation. The code does not establish that the new request answers the question. See `Read Pending Answer` in the [staged Main workflow](/home/auditor/work/n8n/staged/workflow.main.sanitized.json).

### 3. Cancel lookup — NOT CLOSED

**MEDIUM:** The time filter runs only when the day filter leaves **more than one** candidate. If a customer names a day and a time that does not match the sole booking on that day, the lookup still selects that booking and presents it for cancellation. Confirmation remains required, but the selected booking is not the one named.

The “which one?” reply also does not itself bind a pending cancellation-choice intent; successful continuation depends on the model classifying the next answer as `cancel`. Thus an answer containing only the requested day and time can be routed elsewhere. See `Cancel Lookup` in the [staged Main workflow](/home/auditor/work/n8n/staged/workflow.main.sanitized.json).
