- **HIGH — Control stripping can turn text that is not a clear yes into consent.** `Merge State` removes C0/C1 characters before `Read Pending Answer` tests the text. Consequently, `ye\u0000s` becomes `yes` and can pass the consent test at a pending confirmation if the model also returns `confirm`. The test is against the altered text, not the turn’s original text. See [staged Main](/home/auditor/work/n8n/staged/workflow.main.sanitized.json) and the H6 test in [hardening-main.test.cjs](/home/auditor/work/tests/unit/hardening-main.test.cjs:283).

- **MEDIUM — The reschedule rewrite does not establish that the turn answers the question.** `Read Pending Answer` rewrites any model `book` intent to `reschedule` when the previous `last_intent` is `reschedule_ask` and a target ID exists. It does not check the text or session age. `Merge State` clears the confirm stamp on a new session but retains `last_intent` and `cancel_target_id`, so a later independent booking request can enter the reschedule lane. A further confirmation is still required before the move. See [staged Main](/home/auditor/work/n8n/staged/workflow.main.sanitized.json).

- **MEDIUM — “Which one?” cannot distinguish two bookings on the same day.** `Cancel Lookup` matches a named day and proceeds only when exactly one row matches; its reply asks the customer to tell it the day. Two bookings on the same day therefore keep producing the question even if the customer supplies the requested day. See [staged Main](/home/auditor/work/n8n/staged/workflow.main.sanitized.json).
